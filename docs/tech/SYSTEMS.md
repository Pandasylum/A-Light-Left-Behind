# SYSTEMS — carte du code

Statut : projet Godot initialisé dans `game/` (2026-11-10), squelette sans gameplay.
Mis à jour par Claude Code à chaque PR touchant l'architecture. 100 lignes maximum.
Format d'une entrée : `chemin` — rôle en une ligne — dépendances principales.

## Systèmes
`game/project.godot` [input] — actions Input Map provisoires (liste dans docs/tech/TECHNICAL.md) — aucune
`tools/` — godot.sh (télécharge/lance Godot 4.7.2 épinglé), check_project.sh (import + chargement headless) — aucune

`game/core/save_service.gd` — autoload SaveService (sans class_name, conflit Godot) : save_slot (synchrone)/load_slot/slot_exists, JSON versionné ; save_slot_threaded = même écriture sur un fil de travail (données copiées, file par emplacement où la plus récente remplace l'attente, signal save_finished sur le fil principal ; à utiliser en jeu : écriture complète du tour ≈ 45 ms), flush() d'office avant toute lecture/écriture synchrone et à la destruction du service ; checksum = SHA-256 de la chaîne JSON des données stockée telle quelle dans l'enveloppe (aucune re-sérialisation, donc stable pour les flottants) ; écriture atomique (.tmp relu et validé, puis renommé), sauvegarde précédente valide = copie de repli .bak ; chargement : principal inutilisable (absent, tronqué, JSON illisible, version inconnue, section d'enveloppe manquante) → repli sur .bak + push_warning ; aucun fichier utilisable → push_error, résultat damaged, fichiers au contenu invalide renommés .corrompu (jamais supprimés ni écrasés ; fichier intact mais trop récent/non migrable laissé en place), is_slot_damaged() pour l'écran-titre ; migrations par étapes register_migration(version, Callable) enchaînées jusqu'à format_version — aucune
`game/core/autosave.gd` — Autosave (Node, class_name, pas d'autoload ; instancié dans sponge_test.tscn seulement ; process_mode ALWAYS : l'export étalé continue pendant la pause) : sauvegarde automatique sur événements, un seul emplacement (SLOT_ID « partie »), setup(pièce, ToolController, service) ; déclencheurs : outil rangé (tool_stowed), fin de surface (surface_finished de chaque CleaningSurface de la pièce, reliée par setup() ou watch_surface() ; surface d'office et chargement n'émettent pas), fermeture du jeu (handle_quit : auto_accept_quit coupé, save_and_wait puis quit), request_save() pour les déclencheurs à venir ; déclencheur reçu pendant une action d'outil = en attente jusqu'à sa fin ; export des faces étalé sur plusieurs images (export_budget_usec 2 ms provisoire, liste figée au départ, face libérée ou sortie de la pièce ignorée, suspendu pendant une action) ; déclencheurs reçus avant la fin de l'export fusionnés en une écriture (export repris du début) ; écriture par save_slot_threaded, résultat relayé par save_completed ; save_and_wait() bloquant (sortie, retour au menu et Quitter de la pause : action annulée, export terminé d'un coup, écriture attendue) — SaveService, CleanableFace, CleaningSurface, ToolController, ToolSlots
`game/tests/save_roundtrip_test.gd` — SaveService (dossier user://test_saves/) : aller-retour, altération, fichier tronqué, JSON invalide, version inconnue/trop récente, section manquante, principal supprimé, repli sur .bak, principal + .bak illisibles (.corrompu, état endommagé), copie de repli préservée à la sauvegarde, un fichier figé par version de format (VERSION_FIXTURES), chaîne de migrations, écriture en file (résultat, données copiées, destruction du service, rafale, ordre avec le synchrone, fichiers illisibles) ; test : `tools/godot.sh --headless --path game --script res://tests/save_roundtrip_test.gd` (code de sortie non nul au premier échec) — save_service.gd
